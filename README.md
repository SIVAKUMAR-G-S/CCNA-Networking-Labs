# CCNA Networking Labs

## Overview

Welcome to my **CCNA Networking Labs** repository!

This repository documents my hands-on learning journey through the **CCNA 200-301** curriculum using Cisco Packet Tracer and Cisco IOS CLI.

My goal is to strengthen my networking fundamentals through practical configuration, verification, analysis, and troubleshooting while preparing for a career in **Network Engineering**.

## Learning Objectives

- Configure networking technologies.
- Understand networking protocols.
- Verify configurations using Cisco IOS commands.
- Analyze network connectivity.
- Troubleshoot network issues.
- Document practical labs and results.

## Tools & Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- Wireshark
- Windows and Linux Networking Utilities
- TCP/IP, Ethernet
- IPv4 and IPv6

## Learning Roadmap

- **Fundamentals:** OSI Model, TCP/IP, Ethernet, ARP, ICMP, IP Addressing, Subnetting
- **Switching:** VLANs, Trunking, Inter-VLAN Routing, STP
- **Routing:** Static Routing, RIP, EIGRP, OSPF, BGP
- **Network Services:** DHCP, DNS, NAT/PAT, ACLs
- **Security & Automation:** Network Security, Device Security, Network Automation

## Lab Documentation

Each lab includes:

- Objective and Network Topology
- IP Addressing
- Device Configuration and IOS Commands
- Verification and Connectivity Testing
- Troubleshooting
- Screenshots and Learning Outcomes

## Lab Methodology

**Configure → Verify → Understand → Troubleshoot → Document**

I focus on understanding how networking technologies work, not just achieving successful connectivity.

## Skills Being Developed

- Routing and Switching
- OSPF, EIGRP and BGP
