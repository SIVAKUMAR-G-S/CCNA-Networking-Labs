# Dynamic Routing Labs

## Overview

Welcome to my **Dynamic Routing Labs** repository!

This repository documents my hands-on learning and practice of dynamic routing protocols using **Cisco Packet Tracer**.

The main goal is to understand how routers exchange routing information, select the best paths, and communicate across multiple networks.

## Learning Objectives

Through these labs, I aim to:

- Understand how dynamic routing protocols work.
- Configure and verify routing protocols.
- Analyse routing tables and route selection.
- Understand metric and administrative distance.
- Test connectivity between multiple networks.
- Troubleshoot routing issues.

## Routing Protocols

The following protocols are included in my learning roadmap:

- RIP (Routing Information Protocol)
- EIGRP (Enhanced Interior Gateway Routing Protocol)
- OSPF (Open Shortest Path First)
- BGP (Border Gateway Protocol)

## Tools & Technologies

- Cisco Packet Tracer

- Dynamic Routing Protocols

## Learning Methodology

**Configure** – Implement routing protocols using Cisco IOS commands.

**Verify** – Check routing tables and protocol operation.

**Analyse** – Understand route selection and network communication.

**Troubleshoot** – Identify and resolve routing issues.

**Document** – Record configurations and learning outcomes.
