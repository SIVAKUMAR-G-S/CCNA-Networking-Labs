# Static Routing Configuration

## Objective
Configure static routing to enable communication between multiple networks using Cisco Packet Tracer.

## Tools Used
- Cisco Packet Tracer
- Cisco IOS CLI

## Concepts Covered
- Static Routing
- IP Addressing
- Routing Tables
- Next-Hop Configuration

## Configuration Commands
Document the commands configured on each router.

## Verification
- show ip route
- show ip interface brief
- ping

## Result
Successfully configured static routes and verified connectivity between networks.
