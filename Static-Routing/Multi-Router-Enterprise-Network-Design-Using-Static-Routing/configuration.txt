IMPORTANT NOTES
- The commands below are transcribed from the five screenshots in the order supplied.
- All static routes shown use subnet mask 255.0.0.0, exactly as displayed in the screenshots.
- The first screenshot (Router0) shows only part of the running configuration. Its visible interface details and static routes are included, but missing interface configuration has not been guessed.
- The remaining router screenshots show static-route commands and hostnames. Interface IP configurations are not fully visible in those screenshots.
- Before applying these commands to another topology, verify interface names, IP addresses, subnet masks, and next-hop reachability.
